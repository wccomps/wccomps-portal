Before competition day: set up the Competition page: Max Team Members and the Controlled Apps (the apps Start and Stop open and close), the Schedule, the Start Message (posted to every active team when the competition starts) and Sync Metadata under Quotient Integration.

Check readiness: press Run Checks under Readiness Check. It checks that the team accounts exist and are in the right groups, the Discord settings are set, a packet went out for the event and every team on the list has a delivered copy, the start message is set, Quotient answers and is synced, and no tickets, red team findings, incident reports, inject grades or orange assignments are left from before. Some results have a button that fixes them or a link to where they are fixed.

Start: press Start Competition under Competition Controls. If a start time is set under Schedule, the bot starts it at that time on its own. The controlled apps open to blue teams, the active teams' accounts are turned on, Quotient metadata is synced, and the start message is posted to every active team, if one is set.

What can go wrong: with no controlled apps configured it refuses. If some apps or accounts didn't change, the progress list marks them and says the run is incomplete: run Start again.
